# Combat & Skilling Vitals — Launch Inventory

**Replaces 45 plugins (30 Hub, 15 built-in, 33 partial); adds 18 features**

- **Full replacements:** 12 plugins (11 Plugin Hub, 1 built-in)
- **Partial replacements:** 33 plugins (19 Plugin Hub, 14 built-in)
- **Net-new features:** 18 capabilities that none of the 45 replaced plugins offers

## Scope & Methodology

This inventory audits the **finished Plugin Hub launch state** of **Combat & Skilling Vitals** (`combat-vitals`) against the actual Java source code:

- **Included (launch state):** `main` (`d0672b4`) plus the kept launch PRs approved under the Hub launch freeze:
  - **RUNELITE-519** (PR #82, `ForestryMarks`, `ForestryHighlightOverlay`): Forestry event object/NPC solvers, Friendly Entling overhead prune reader, and 3-slot Struggling Sapling solver.
  - **RUNELITE-442** (PR #81, `PillarSource`, `PillarSplit`, `PillarSupplies`, `PillarPresets`, `PillarController`): 14 status-pillar sources, split bars (up to 4 simultaneous pillars), supply/ammo/charge readouts, and saved + weapon/skilling auto-switching presets.
  - **RUNELITE-486** (PR #78, `AllTime`, `CardTimers`, `LiveCardHold`): Live tab `Paused` card hold and persisted per-account `All time` stats.
  - **RUNELITE-478 / RUNELITE-479** (PRs #74–#75, `GemstoneCrabWatcher`): Gemstone Crab burrow/crawl alert fixes and cave `57631` click detection.
- **Listed separately below (not counted in launch totals):** **RUNELITE-521** (PR #83) and **RUNELITE-524** (PR #84), which are parked behind the Plugin Hub submission freeze.
- **Full vs. Partial rule:**
  - **Full:** Covers the target plugin's core job end-to-end so most players can uninstall it without losing its primary workflow (minor stylistic differences noted).
  - **Partial:** Replaces a dedicated workflow or everyday slice of the target plugin while leaving out specific overlays, mechanics, or secondary modes (explicitly documented in the right-hand column).
- **Reconciliation with earlier README table:** The summary table in [README.md](../README.md) previously listed **18** plugins (`8` Hub + `10` built-in, with 5 skilling plugins grouped onto one row) and marked only *GP Per Hour* as partial. Code verification reclassifies **13** of those original 18 as **Partial** (`5` **Full**) and adds **27** further plugins (`22` Hub + `5` built-in) covered by features shipped since PR #62 and the kept launch branches (`18 + 27 = 45`).
